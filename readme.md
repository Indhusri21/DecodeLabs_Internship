# TODO-LIST

This Python program is a command-line application that manage daily tasks.

Easy to add new tasks while built-in checks automatically prevent blank entries.

The program displays all current tasks in an organized, numbered list for easy viewing.

An editing feature allows users to either rename a task or append extra details to it.

Remove completed or unwanted tasks from the list by typing their task number.

A built-in search option allows users to quickly find tasks using case-insensitive keywords.

Tasks can be marked as finished, which automatically adds a [DONE] tag to the task name.

Exception handling is included to prevent the program from crashing.

Index checks ensure that typing an out-of-range task number will not break the application.

The application runs smoothly inside an interactive loop until the we choose to exit.

# EXPENSE TRACKER

A simple Python script to log expense amounts, list them, and calculate the total spent.

List Storage: Saves expenses in a list (expenses).

Input Validation: Handles invalid numbers safely using try-except.

Float Support: Supports decimal amounts (e.g., 45.50).

Itemized List: Prints each recorded expense with an index using enumerate().

Total Calculation: Sums up expenses using sum() and formats the output to two decimal places (₹).
